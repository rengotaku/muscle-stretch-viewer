# ADR 0003: ポーズのプリセットは localStorage に独立関節の角度だけを保存する

## 背景

関節スライダーで作ったポーズを、名前を付けて保存し、あとで呼び出したい（#10）。サーバを持たない構成（ADR 0001）なので、保存先はブラウザの中に置く必要がある。

## 決定

- 保存先は localStorage。キーは `muscle-stretch-viewer.presets.v1`、値は `[{ name, angles: { <独立関節名>: <rad> } }]` の JSON 配列
- 保存するのは独立した 71 関節の角度だけ。連動関節は読み込み時に `setJointAngle` で計算し直す
- 同じ名前で保存したら置き換える
- 保存データが読めない（getItem の例外・壊れた JSON・配列でない値）ときは、保存も削除も中止し、既存データを上書きしない。画面のプリセット欄にエラーを出す
- 配列の中の個々の要素が不正なだけなら、その要素を読み飛ばす

## 捨てた案

- **サーバやクラウドに保存する**: サーバを持たない前提と合わない
- **連動関節の値も保存する**: モデル更新で多項式が変わると、保存値と計算値が食い違う
- **読めないデータを空一覧として扱う**: 次の保存で既存データを消してしまう（codex レビューで指摘され採用）

## 変えてよい前提 / 壊すと危ない前提

- **変えてよい**: 一覧の並び順、名前の長さの上限、画面の配置
- **壊すと危ない**:
  - 保存形式を変えるときはキーの版（`v1`）を上げる。同じキーで形式を変えると、古いデータが「読めない」扱いになり、保存も削除も止まる
  - 読み取りに失敗したら書き込まないこと
  - 端末間・タブ間の同期はしていない（#13）。別タブで変えた内容はページの再読み込みで反映される
